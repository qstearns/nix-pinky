# CLAUDE.md

## Keybindings

Don't add or change keybindings (niri binds in `niri/config.kdl`, keyboard remaps, app shortcuts) straight away. First propose them and wait for confirmation:

- Suggest the key combo, plus an alternative or two when there's a real choice.
- Spell out the trade-offs: what the combo currently does or conflicts with (check the existing binds), how easy it is to press, whether it fits the existing pattern (e.g. Mod+Shift+X as a variant of Mod+X), and any implementation caveats (e.g. needing a helper script).
- Only edit the config once the user has picked one.
